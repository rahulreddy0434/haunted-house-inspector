# Design screens (reference for Kiro)

Mockups from the "Haunted House Inspector - Screens" canvas (Nov 13, 2026).
Each .dc.html file is one screen with inline styles. Copy spacing, sizes, colours, corner radii, wording and order.
Ignore the <x-dc> wrapper, support.js and the {{ }} placeholders.

1 Main = home (upload and questions), 2 Result = normal result, 3 Emergency = emergency result,
4 Booking = pick a time, 5 ProJobs = Pro job list (desktop), 6 ProJob = Pro job page (desktop),
7 HauntedHome and 8 HauntedResult = Haunted mode.

Later decisions override these mockups: see .kiro/specs/screens-polish (deliberate differences).
